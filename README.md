# wsearch

## Description
A simple hobby project. It performs web searches using the DDGS (DuckDuckGo Search) library. Small, simple, and easy to use—but NOT professional-grade.

## How to use
(why would you use this go use google chrome the code is bad)

### Windows
1- Install app.py
2- Open powershell
3- write $ python app.py -q "cats" -m 3

-q or --query --> **Query**. Like searching on Google
-m or --max-results --> **Results Number**. How many responses would you like to receive

### Linux
1- Install app.py
2- Open Console Emulator (Example: Konsole, xfce-console)
3- write $ python app.py -q "cats" -m 4

**Why are the steps almost the same?** Because **PowerShell** likes **Bash** syntax.
